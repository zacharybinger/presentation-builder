# Example prompts for invoking the Presentation Builder skill

**From dense technical notes**

> Use the presentation-builder skill. Turn the attached Slurm/Slinky notes into an interactive 12-slide technical explainer for HPC engineers. Make the job lifecycle a persistent SVG that develops over five reveals. Use the Explainer direction but add a vivid editorial opening. Include an interactive request/queue simulation, speaker notes, and browser validation. Do not invent benchmarks.

**From a document**

> Use presentation-builder to make a conference talk from this research paper. Preserve the methods and findings accurately and cite figures. Prioritize large visual comparisons over lists; include one data-linked chart and two animated mechanism diagrams. Make it readable from the back of a room.

**Agent demo**

> Use presentation-builder. Create a five-minute web-native keynote explaining an agent's retrieval → reasoning → action lifecycle. Choose a Signal/Nocturne blend with distinctive typography, subject-specific visual metaphor and a real interactive trace explorer. Use thinking-orbs only to indicate a genuine active state. Validate in Playwright and package for offline delivery.

**Investor pitch**

> Use presentation-builder for a 10-slide startup pitch with no generic startup templates. Use an editorial art direction derived from the product, strong visual pacing, careful data source labeling, one demo scene and a concrete ask. Ship exactly one offline standalone `presentation.html` and one matching `presentation.pdf`; validate both with the bundled exporter and Playwright.

**Refine existing deck**

> Use presentation-builder to restyle this HTML deck without changing its claims, diagrams, or working interactions. Show three visual directions, adapt the selected one to every scene, and re-test all navigation, deep links, and interactive controls.

**Offline use**

> Use presentation-builder and its zero-dependency deck template. Do not load fonts, images, scripts, or CSS from a CDN. Generate exactly two offline deliverables: one self-contained `presentation.html` and one `presentation.pdf`, with no CDN, separate JS, CSS or media files.

**GSAP + Design DNA example**

> Use presentation-builder to make an interactive technical talk about [system]. Extract a Design DNA profile from the attached design references, articulate an interaction thesis for the main explorable diagram, choose LottieFiles-inspired motion personality, and use locally bundled GSAP seekable timelines if they clarify the process. Ship **only** `presentation.html` and `presentation.pdf`, preserving the final diagram in the PDF. Inspect every page and run the offline artifact validator.
